# Project Decisions Log

**Purpose:** Preserve only durable architectural and product decisions so context survives across conversations and sessions.

Keep entries short, factual and dated. Do not log chatter or temporary states.

---

## How to use

- Create this file in the root of any serious project repository.
- Add a new entry only when a lasting decision is made.
- Prefer clarity over completeness.
