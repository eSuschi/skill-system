# System Knowledge Base

This directory is the persistent operational memory of the multi-skill operating system.

Maintained primarily by **system-learning-core**.

## Purpose

Store only durable, high-signal lessons, patterns and risks learned from real projects and decisions.  
The goal is to make future projects and other skills start smarter without adding bureaucracy or noise.

## Files

- `LESSONS.md` — dated high-signal lessons
- `PATTERNS.md` — recurring successful patterns
- `RISKS-AND-ANTI-PATTERNS.md` — what repeatedly hurts quality or coherence

Additional domain-specific files may be added only when volume clearly justifies them.

## Rules

- Quality over quantity.
- Evidence-based entries only.
- Keep files short and scannable.
- Prune low-value content under system-engine guidance.
- Never use this store for temporary notes or project-specific chatter (those belong in project DECISIONS.md).

This knowledge base supports Article 5 of the Quality Constitution (Learning is Mandatory).
