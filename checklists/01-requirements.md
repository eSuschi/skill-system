# Checklist – Requirements Clarifier

- [ ] Primary goal is clearly stated in one sentence
- [ ] Target user / audience is defined
- [ ] Success criteria are measurable or at least unambiguous
- [ ] Explicit out-of-scope items are listed
- [ ] Platform / tech constraints are known
- [ ] Quality bar is agreed (MVP vs production-grade)
- [ ] Any hard deadlines or external dependencies are noted
- [ ] Both sides confirm the brief is complete enough to start architecture
