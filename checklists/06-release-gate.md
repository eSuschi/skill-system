# Checklist – Release Gate (Mandatory)

### Functionality
- [ ] Core user flows work end-to-end
- [ ] No Critical bugs
- [ ] No High-severity bugs left unresolved

### Quality & Polish
- [ ] Visual appearance is professional
- [ ] Language is consistent (no mixed Polish/English in user-facing text unless intentional)
- [ ] Error states and edge cases are handled reasonably

### Process
- [ ] Requirements were clear
- [ ] Architecture decisions are documented where non-obvious
- [ ] Code has been through Principal Code Review and Final Auditor
- [ ] Repository is in a clean, presentable state

### Final Decision
- [ ] Ready to ship / show
- [ ] Or explicitly marked as internal prototype only
